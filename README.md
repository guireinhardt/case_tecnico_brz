# case_tecnico_brz

Diagnóstico e limpeza dos arquivos de precatórios (pagamentos do tribunal,
lista do tribunal e exportação do hub).

## Estrutura

```
case-candidato/   material original do desafio (não é alterado)
limpeza/          código da limpeza
tests/            testes (pytest)
```

## Como rodar

Requer Python 3.10+.

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows  (Linux/Mac: source .venv/bin/activate)
pip install -r requirements.txt
pytest
```
